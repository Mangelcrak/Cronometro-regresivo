# ⏱️ Cronómetro Regresivo

**Controla tu tiempo de forma sencilla.**

Cronómetro Regresivo es una aplicación web diseñada para configurar y visualizar cuentas regresivas de manera práctica. Su interfaz adaptable permite utilizarla tanto en computadores como en dispositivos móviles.

## ✨ ¿Qué puedes hacer?

- ⏳ Configurar una cuenta regresiva.
- ▶️ Iniciar y pausar el contador.
- 🔄 Reiniciar el tiempo cuando lo necesites.
- 🚩 Registrar marcas de tiempo.
- 🖥️ Activar el modo de presentación para ver el contador en grande.
- ⛶ Utilizar la pantalla completa.
- 📱 Usar la aplicación desde diferentes dispositivos.

## 🧰 ¿Cómo fue desarrollado?

Este proyecto utiliza tecnologías web fundamentales:

- **HTML5** para organizar el contenido.
- **CSS3** para crear la interfaz y adaptar el diseño a diferentes pantallas.
- **JavaScript** para controlar el tiempo y las interacciones.

## 🚀 Pruébalo

1. Visita la demostración en línea.
2. Introduce el tiempo que deseas configurar.
3. Inicia el contador y utiliza sus controles.
4. Prueba el modo de presentación y la pantalla completa.
